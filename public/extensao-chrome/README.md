# Extensão Chrome - Portal G CAC (Emissor Automático de Certidões)

Esta extensão conecta-se ao **Portal G CAC** para preencher automaticamente com um clique todos os dados do cliente nos sites oficiais de emissão de certidões (TRF, TJ, STM, TSE, Polícia Federal, etc.).

## Como Instalar no Google Chrome:
1. Abra o navegador Google Chrome.
2. Acesse a barra de endereços e digite: `chrome://extensions` (ou vá em Menu > Extensões > Gerenciar Extensões).
3. Ative a chave **Modo do desenvolvedor** no canto superior direito.
4. Clique no botão **Carregar sem compactação** (Load unpacked).
5. Selecione esta pasta `extensao-chrome` (onde se encontra o arquivo `manifest.json`).
6. Pronto! O ícone do Portal G CAC aparecerá na sua barra de extensões.

## Como Usar:
1. No Portal G CAC, acesse a ficha do cliente.
2. Na aba **Certidões Criminais**, clique no botão **Emitir Certidão** ao lado do tribunal desejado.
3. A extensão reconhecerá automaticamente o cliente selecionado.
4. Na página do tribunal que se abrir, clique no botão flutuante **⚡ Preencher com Portal G CAC** ou abra o ícone da extensão.
5. Os dados (Nome, CPF, RG, Filiação, Nascimento, Endereço, etc.) serão preenchidos instantaneamente.
6. Resolva o teste de segurança (CAPTCHA) exigido pelo tribunal e clique em Emitir!
